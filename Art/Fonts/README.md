# Bengali fonts for signage

Downloaded on 2026-11-02, with the owner's approval, from Google Fonts' repository, `https://raw.githubusercontent.com/google/fonts/main/ofl/<family>/`. Every family is under the SIL Open Font License 1.1; its `OFL.txt` sits beside it.

The OFL allows bundling and embedding in a game, and rendering text with the fonts into textures. The fonts may not be sold on their own. A modified font may not keep the reserved font names.

These are source files for the sign atlas tool (D-09). They live outside `Assets`, so Unity does not import them.
