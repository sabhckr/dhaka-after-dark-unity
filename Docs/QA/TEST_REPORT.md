### What the DADC tests prove

- **Exact round trip:** a real Farmgate chunk (`c_7_-30`) and a synthetic chunk with every optional field decode back exactly.
- **Unity frame:** a node at three.js (3941.77, −14893.33) decodes to east 44177 cm and north 39333 cm from the chunk's south-west corner.
- **Refusals:** the encoder refuses a 1 mm value, a quarter level, an unknown key, an underived node id, a malformed edge id and a wrong origin.
- **Corrupt files:** truncated data, bad magic, trailing bytes and an unknown format version all throw.
- **Export and verify:** the export is deterministic, and the verifier passes on a good export but fails on a changed source (both the hash and the deep compare).
