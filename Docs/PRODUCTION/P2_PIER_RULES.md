## What changed in the code

| File | Change |
|---|---|
| `Runtime/World/NeighbourRails.cs` (new) | Reads the elevated tracks of a chunk's eight neighbours from their chunk files, read-only, and translates them into the chunk's centimetres. Each file is decoded once per directory (cached). Only chunks with an elevated track of their own read them: 64 of 1,303. |
| `Runtime/World/Dadc.cs` | `DadcChunk.NearRails`, the neighbours' elevated tracks. The file format is unchanged. |
| `Runtime/Core/Streaming/ChunkStreamer.cs` | Attaches the neighbours' tracks after loading a chunk, on the worker. |
| `Runtime/World/Structures.cs` | **Decks:** each track is joined across chunk borders into one chain, and twins are paired with the neighbours' tracks too. A deck is decided along the whole run (within 120 m of the chunk). The chunk builds only the girder pieces inside its square and the piers it owns: the south and west edges are in, the north and east edges out, with a 5 cm snap. **Piers:** on the 30 m grid as before. A place in a junction pad or on a crossing road (more than 30° off the deck's direction) slides along the deck in 0.25 m steps up to 4 m, else it is spanned. Two places are never spanned in a row: the second is then built and counted as "kept". A place under 25 m from the last pier is not built. A place within 8 m (the twin limit) of a pier already placed is not built again, which covers a deck split into runs. |
| `Runtime/World/StreetFurniture.cs` | Counters `PiersSlid`, `PiersOverRoad`, `PiersKept`, and the scratch lists the rule needs (no new allocation per build). |
| `Editor/Infra/InfraSurvey.cs` | The checker reads the neighbours' tracks too, so a pier's tracks match the builder's. Span limits are written out as their own numbers: 25 m, and 61 m on the deck's main axis. They are no longer taken from the builder, so a change to the builder's rule shows. Only a pier ahead or behind (within 45° of the deck) counts as a span, not one beside it on a side-by-side deck. |

The long-span limit is on the main axis because on a skewed deck one grid place spanned is up to 64 m along it. The register gives the length along the deck too.
